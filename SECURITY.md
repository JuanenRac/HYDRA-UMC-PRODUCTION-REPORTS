## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a production reporting system, a security flaw can lead to corporate espionage or masking of production defects. If you discover a vulnerability affecting the **report generation parameters**, **PDF injection**, or **unauthorized email dispatch**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows generating fake quality reports, bypassing access controls to production logs, or leaking factory KPIs to external parties.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
